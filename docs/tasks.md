# Divisão de tarefas

Cada tarefa vira uma issue no GitHub, uma branch e um PR.

| #  | Tarefa                                   | Entrega                                                                        |
|----|------------------------------------------|--------------------------------------------------------------------------------|
| T1 | Fundação do projeto                      | Monorepo, documentação do problema, regras hipotéticas e contrato do dispositivo |
| T2 | Back-end: banco, seed e API de consulta  | SQLite, clientes/bombonas/dispositivos fictícios, endpoints de leitura          |
| T3 | Back-end: telemetria e motor de regras   | `POST /api/telemetria`, RN04–RN16, eventos em tempo real (SSE), testes          |
| T4 | Back-end: movimentações e alertas        | Saída para entrega, coleta, resolução manual de alertas                         |
| T5 | Simulador de dispositivos                | Processo que imita os rastreadores e os cenários de desvio                      |
| T6 | Front-end: mapa ao vivo                  | Mapa estilo iFood com cercas, trilhas e indicadores                             |
| T7 | Front-end: operação                      | Painel da bombona, alertas, clientes e controles da simulação                   |
